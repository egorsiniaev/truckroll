# firmware

ESP32 DevKitC V4 (WROOM-32) mini charger on [MicroOcpp](https://github.com/matth-x/MicroOcpp), OCPP 1.6J.
Built with PlatformIO. Low voltage only: a 12 V lamp is the "car", a relay is the contactor.

Parts, pin plan and the charging sequence: [HARDWARE.md](HARDWARE.md). Not started yet.
